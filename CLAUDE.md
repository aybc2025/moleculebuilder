# בונה המולקולות (Molecule Builder)

A Hebrew (RTL) PWA for kids aged 7–12: they build real molecules from "atoms with hands", the app recognises what they built, and shows it in 3D. It's static and served from GitHub Pages.

## On opening this repo, run automatically
```
node --test tests/*.test.mjs          # core logic: 12 tests, should all pass
python3 -m http.server 8765           # then open http://localhost:8765
```
There is no build step and no `npm install`. v2 was verified in headless Chromium (Playwright): mobile 390×844 and desktop 1280×860 flows, with no console errors. The full test suite passed.

## package-lock.json and CI
There's no `package.json`, so there's no lockfile. `.github/workflows/test.yml` only runs `node --test` (Node 22). The skill's bootstrap/locked npm states don't apply here. If you add npm deps, add the lockfile and switch the workflow to `cache: 'npm'` + `npm ci`.

## What you can NOT do here, even if asked
- Turn on or change GitHub Pages settings (the repo owner does that in the GitHub UI).
- Push straight to `main`. Work on a branch and let the owner merge.
There are no secrets, backend or Firebase. If one is ever needed, name the manual step for the user instead of working around it.

## Architecture
```
index.html          shell only (header, 3 screens, panel). CSP meta: no inline scripts or styles
css/tokens.css      the design system below, and nothing else
css/*.css           base / layout (phone→desktop) / board / screens
js/main.js          wiring: store events → UI modules; game rules (stars, glide, celebrate)
js/data/            atoms.js (colors, hands, radii) + molecules-*.js (graph per molecule)
js/core/            pure logic, no DOM, unit-tested
  store.js          single source of truth + event channel {kind, payload, nonce}
  chemistry.js      hands, connectivity, Hill formula, analyze()
  match.js          graph isomorphism → exact / isomer / new
  geometry3d.js     VSEPR-style 3D embedding from any graph (deterministic)
  layout2d.js       PCA projection of the 3D shape onto the board
  placement.js      free spot for a new atom
  progress.js       stars in localStorage (try/catch, works without storage)
js/ui/              DOM modules: board, boardInput, tray, status, moleculePanel,
                    viewer3d, challengeBar, challengesScreen, atomsScreen, miniMolecule,
                    celebrate, nav, updateBanner, pegs, dom
vendor/             three.min.js r124 + OrbitControls (global THREE; not ES modules)
fonts/              Secular One + Varela Round woff2 (Hebrew + Latin subsets), self-hosted
icons/              generated by icon-design/make_icons.py
service-worker.js   versioned cache; bump VERSION on every release
```
Non-obvious choices:
- **A molecule is defined once** as `atoms` + `bonds` ("0-1 0=2 1#3"). Level, counts, board layout, 3D shape and recognition are all derived from it. Don't add hand-written coordinates or per-molecule layout code (v1 had three copies of this and they drifted).
- **Logic never knows about animation.** The store emits events. `board.js` keeps a separate `display` position map so the glide can interpolate without touching the store.
- **Atom colors live only in `atoms.js`.** `installAtomColors()` turns them into CSS variables (`--atom-H`…). This is CSSOM, so it's allowed by the CSP.
- **`.stage { display: contents }` on phones** lets the tray sit between the board and the toolbar. Desktop turns it back into a column.
- `vendor/` scripts are classic scripts loaded before the module. Don't upgrade Three.js without replacing OrbitControls to match.

## Intentional decisions (don't revert without asking)
- **Stack: vanilla ES modules, no React/Vite, no build.** The owner approved this deviation from the app-development skill's default. Pushes deploy as-is to GitHub Pages and the app works offline.
- **Recognition checks structure, not atom counts.** All atoms connected, every hand used, and graph isomorphic to a known molecule. Same formula with a different structure is reported as an isomer.
- **Recognition is automatic.** "בדוק" (check) is a hint button that explains what's missing and pulses those atoms.
- **Bond cycle:** none → single → double → triple → removed. If there are no free hands to upgrade, the bond is removed instead of showing an error, so a bond can always be undone.
- **Tapping a tray atom while an atom with free hands is selected** places the new atom next to it and bonds them.
- **Unsolved challenge cards never reveal the structure**, only the ingredient atoms (owner request). "הראה לי" (show me) loads the solution as a demo, which never awards a star.
- **A star goes to any known molecule the child builds by hand**, in or out of a challenge.
- 38 molecules in 4 levels by atom count: קל ≤3, בינוני 4–6, מאתגר 7–10, אלוף 11+. The owner asked for "lots, varied". All texts are kid-level Hebrew and fact-checked.
- Atoms: H C N O S Cl, with CPK colors (the school model-kit convention; the owner approved switching from v1's colors).
- The mobile result sheet opens 900ms after recognition so the celebration on the board is visible first.

## Visual system
- Palette: paper `#f3f6f9` (page/board) · grid `#d6e2ec` (decorative) · ink `#17263a` (text, primary button, bonds) · ink-soft `#52637a` (secondary text, 5.6:1) · surface `#fff` · line `#d9e1e8` (decorative) · line-strong `#7d8fa3` (control borders, 3.3:1) · spark `#f26b1d` (selection, focus, stars; never text) · good `#177a45` on `#e3f4ea` · bad `#b42318` on `#fdecea`.
- Atoms (CPK): H `#F7F7F4` + ink letter, C `#33373D`, N `#3563E0`, O `#E0393E`, S `#E9C22E` + ink letter, Cl `#25994C`.
- Type: Secular One (display, atom symbols, formulas) + Varela Round (body). Scale 1.25: 14/16/20/25/31, line-height 1.6. Formulas use `<sub>` (the fonts lack subscript glyphs).
- Spacing: 4px base (4/8/12/16/24/32/48). Radius: 12 tiles/cards, 20 panels, full for round things.
- Elevation: 0 board, 1 panel (line + faint shadow), 2 floating (sheet, banner, delete chip).
- Motion: ease-out `cubic-bezier(.23,1,.32,1)`, in-out `cubic-bezier(.77,0,.175,1)`. Press 120ms. Atom pop 160ms. Bonds have no animation (frequent). Shake 300ms. Glide into layout 450ms and particle burst 900ms (rare, on recognition). Sheet 280ms in / 160ms out. Reduced motion: no glide or particles (the board flashes green instead), no auto-rotate.
- Signature element: glossy model-kit atoms with small rings ("pegs") for each free hand. Keep everything else quiet.
- RTL: the undo icon is mirrored on its wrapper. Tab arrow keys follow RTL (← = next). No horizontal slide motion anywhere.

## App icons
A water molecule (red O, two white H) as glossy model-kit balls on an ink graph-paper tile. It's the same motif as the board's empty state. Generator: `icon-design/make_icons.py` (draws at 4096, downsamples with LANCZOS). The full set is in `icons/`: 192, 512, 512-maskable (content scaled to 74% for the safe zone), apple-touch 180, favicon 32. All were checked at full size, with a circular mask, and at 96/48px. They're wired into `manifest.json` and `index.html`.

## Deployment
GitHub Pages serves the repo root from the default branch, and merging to it publishes. When you change any file, bump `VERSION` in `service-worker.js` and add new files to its `CORE`/`STATIC` lists (install fails if a listed file is missing). Installed apps then show the "יש גרסה חדשה · רענן" (new version · reload) banner.
